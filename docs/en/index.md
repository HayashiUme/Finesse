# Finesse documentation

Finesse is a self-hosted server management platform for Impostor and Empostor. The dashboard connects to the management plugin on each server and displays live server data; it does not use demo data.

## Contents

- [Installation and connection](./installation.md): Docker, static hosting, plugin setup, ports and API keys.
- [User guide](./guide.md): server profiles, accounts, sessions and security.
- [Management features](./management.md): players, rooms, reports, bans, audit logs and plugins.
- [HTTP API v1](./api-v1.md): authenticated management API and WebSocket snapshots.
- [Public API v2](./api-v2.md): scoped API keys, public server data and custom pages.
- [Extensions](./extensions.md): Lua package format and examples.
- [Dashboard updater](./dashboard-updater.md): verified static-site updates with rollback.
- [Docker troubleshooting](./docker-troubleshooting.md): browser-to-plugin connectivity and container logs.
- [Privacy policy](./privacy-policy.md): browser and server-side data handling.
- [Interface language](./interface-localization.md): supported languages and translation workflow.
