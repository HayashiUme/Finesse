# 公开 API v2 与 X-API

V2 API 用于外部程序读取经过授权的服务器数据。超级管理员在**接口**页面创建以 `sk-` 开头的密钥，并为每个密钥勾选允许访问的端点。密钥只在创建时完整显示；请安全保存并在泄露时撤销。

请求时通过 `X-Api-Key` 请求头传入密钥。远程访问请使用 HTTPS。V2 密钥与管理员登录会话分离，并按端点授权；未获授权的端点会拒绝请求。

## `GET /v2/api/games`

返回当前实例可见的房间及玩家信息。响应包含房间码、公开状态、人数、地图、伪装者数量、房主和玩家列表等字段。房间码只在单个 Impostor 实例内唯一；集中管理多实例时应将服务器 ID 与房间码组合使用。

## `GET /v2/api/monitor`

返回 UTC 时间戳、插件运行时间、服务器版本、运行时平台、CPU 与内存、活动房间和玩家数。字段包括 `uptimeSeconds`、`memoryMb`、`gameCount`、`playerCount` 和 `games`。

X-API 是独立的公开兼容接口，不需要 API Key；配置和响应格式请参阅 [X-API 使用说明](/zh-CN/x-api)。

## 自定义欢迎页

在**接口**页面上传 HTML 后，插件将其保存为 `Finesse/Pages/index.html`，通过 `/index` 访问。根路径 `/` 不会被替换。请勿在欢迎页中嵌入管理密钥或敏感信息。
