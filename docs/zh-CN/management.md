# 管理功能

Finesse 提供服务器总览、玩家与房间管理、审核记录、举报、封禁、广播、插件管理和接口设置。数据来自已连接的 Impostor / Empostor 实例。详细路由见[HTTP API v1](./api-v1.md)，外部只读接口见[公开 API v2](./api-v2.md)。

## 仪表盘与监控

仪表盘显示当前服务器的插件运行时间、Impostor 进程 CPU 与内存使用量、在线玩家、活动房间、已加载插件及举报状态。运行时间指插件运行时间，不代表整个操作系统或服务管理器的运行时间。实时连接通过 WebSocket 推送快照，连接中断时界面会显示错误并重试，不会填充演示数据。

## 玩家与房间

玩家页显示在线客户端，包括尚未加入房间的客户端。可查看玩家详情、踢出玩家并填写原因，或对玩家执行房间封禁。房间详情包含房主、房主 IP、GameId、人数、平台、快捷聊天、伪装者数量、地图、语言和房间内玩家等信息。

房间封禁只由游戏服务器在该房间范围内执行；它不等于持久化的全服封禁。清空房间会断开房间内玩家，并不等于发送游戏结束协议。

## 审计与持久化

管理日志记录登录成功或失败、玩家操作、房间操作、服务器封禁、广播和插件管理结果。最多保留 5,000 条，并保存在可执行文件旁的 `Finesse/audit.json`。账户、举报与封禁数据分别保存在 `Finesse/accounts.json`、`reports.json` 和 `bans.json`。报告最多保存 500 条，接口返回最近 200 条；封禁信息跨重启保留。请定期备份整个 `Finesse/` 目录。JSON 是当前唯一的数据提供程序。

## 举报与服务器封禁

插件可接收游戏举报事件并异步保存。举报被记录表示本服务器收到该事件，不代表已向官方举报服务提交。服务器封禁可以使用 IP 或 Friend Code 匹配，可设置原因和时长，也可设为永久。新增封禁会尝试断开匹配的在线客户端；即使即时断开失败，已保存的封禁仍会在后续连接时检查。IP 可能由多个玩家共享。Friend Code 封禁依赖可信身份插件提供并验证身份。

## 插件管理与 Empostor

插件页展示已加载插件的基础信息，并允许超级管理员在当前运行周期启用、停用或删除插件文件。启停状态不是持久配置，删除操作完成可能需要重启服务器。谨慎操作当前承载管理 API 的插件。

Empostor 构建目标使用 `Empostor.Api` NuGet 程序集，Impostor 构建使用 Impostor API。两者对外提供相同 Finesse 合约，但具体游戏数据和举报事件可受服务器版本、其他插件和运行时状态影响。
