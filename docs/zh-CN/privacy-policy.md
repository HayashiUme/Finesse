# Finesse 隐私政策

生效日期：2026 年 11 月 21 日

Finesse 是自托管管理面板和 Impostor 服务器插件。本政策说明 Finesse 软件处理的数据。部署 Impostor 的运营者负责服务器、配置、备份、访问控制及启用的其他服务。

## 不提供中央账户或分析服务

Finesse 维护者不运营中央账户或分析后端。面板不会向维护者发送使用分析或服务器数据。面板本身不设置身份验证 Cookie。

## 浏览器本地数据

面板会在当前浏览器 localStorage 保存服务器名称和插件地址、语言与外观偏好，以及导入的自定义主题图片。API Key 和密码不会随服务器配置保存。登录会话存放在当前标签页的 sessionStorage，有效期遵循服务器签发的过期时间（目前为八小时）。清除站点数据会移除偏好和会话。

登录或使用管理功能时，浏览器会直接向你配置的 Impostor 地址发送 API Key 或 bearer token 和必要请求。远程服务器请使用 HTTPS；应用仅对本机回环地址允许明文 HTTP 认证请求。请求不携带浏览器 Cookie。

## 插件数据

插件会在 Impostor 程序目录下的 `Finesse/` 子目录写入 JSON 文件。根据使用的功能，这些数据可能包括管理员账户名与密码哈希、含登录 IP 的操作记录、可能包含 IP 或 Friend Code 的封禁信息、举报和自定义页面。实时玩家、房间和进程信息从服务器读取，并发送给已认证的面板客户端。服务器运营者负责这些文件的访问、保留、备份和删除。

`finesse.json` 位于 Impostor 可执行文件旁，包含超级管理员 API Key、管理 API 地址和允许访问的面板来源。请将其作为密钥文件限制访问。

## 第三方请求

面板会向 GitHub 获取公开版本信息和下载文件。GitHub 会收到建立连接所需的常规信息，例如 IP 地址和请求元数据。界面也可能从 Google Fonts 加载字体，Google 会收到提供字体所需的连接信息。Finesse 不会向 GitHub 或 Google Fonts 发送 API Key、密码、服务器快照或玩家数据。

反向代理、托管平台和其他插件可能按自身政策处理连接信息。

## 你的选择与联系

可通过浏览器站点数据设置删除本地保存的服务器配置和偏好，也可以退出登录清除当前会话。服务器端记录由服务器运营者管理；运营者可停止服务器后删除或归档 `Finesse/` 数据目录中的相关文件。软件问题可通过 [Finesse GitHub 仓库](https://github.com/HayashiUme/Finesse)联系维护者。
