# Finesse 使用指南

Finesse 是 Impostor / Empostor 的自托管服务器管理面板。面板不会提供演示服务器数据；登录后直接连接你配置的插件 API。安装步骤见[安装与部署](./installation.md)，管理能力见[管理功能](./management.md)。

## 管理多台服务器

在侧边栏打开**服务器**，可添加、搜索、编辑和删除服务器连接。每条连接拥有独立名称、插件地址和登录会话。服务器列表每秒刷新已登录服务器的玩家与房间数量；无法访问的服务器会显示不可用状态。切换服务器后，玩家、房间、操作记录和实时状态都会切换到该服务器。连接地址保存在当前浏览器。尚未启动的服务器也可先保存配置。删除连接只会删除浏览器里的配置，不会停止或修改游戏服务器。

要管理多台实例，需要在每台 Impostor 上分别安装插件，并为同一主机上的各实例配置不同的管理端口。单独托管面板时，每个插件都要将面板来源加入 `allowedOrigins`。

## 账户、登录与会话

超级管理员使用 `finesse.json` 中的 API Key 登录，并可创建普通管理员账户。普通管理员可以管理玩家和房间，但不能创建或删除账户。用户名为 3–32 位 ASCII 字母、数字、点、短横线或下划线；密码为 12–256 个字符。账户、PBKDF2-SHA256 密码哈希和头像存储在可执行文件旁的 `Finesse/accounts.json`。更新插件时请保留 `Finesse/` 数据目录。

会话有效期为八小时，并保存在当前标签页的 `sessionStorage`。刷新页面会恢复现有会话，不会再次生成登录提示或审计记录；退出登录会立即清除本地令牌并请求服务器撤销会话。重启服务器会使现有会话失效。

一次登录失败后，下次尝试需要回答简单算术验证题。同一 IP 或账户在 15 分钟内失败五次会锁定 15 分钟。登录成功与失败都会写入管理日志。这些计数器保存在内存，服务器重启后清零；算术题不能替代反向代理限流。

## 安全边界

管理 API 使用 bearer token，不使用身份验证 Cookie；API Key 和密码不会保存到服务器连接配置中。远程部署应为面板与插件 API 均配置 HTTPS，并在 `allowedOrigins` 中填写精确的面板来源。仅在浏览器和插件运行于同一主机时，开发场景才允许使用 HTTP 回环地址。不要将管理 API 直接暴露到不可信公网。

更完整的安全与数据处理说明见[隐私政策](./privacy-policy.md)和[API v1 认证说明](./api-v1.md)。
