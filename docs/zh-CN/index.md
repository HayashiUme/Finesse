# Finesse 文档

Finesse 是适用于 Impostor 和 Empostor 的自托管服务器管理平台。仪表盘直接连接各服务器上的管理插件，展示实时服务器数据，不使用演示数据。

## 文档目录

- [安装与连接](./installation.md)：Docker、静态托管、插件配置、端口和 API Key。
- [使用指南](./guide.md)：服务器连接、账户、会话和安全。
- [管理功能](./management.md)：玩家、房间、举报、封禁、管理日志和插件。
- [HTTP API v1](./api-v1.md)：认证管理接口和 WebSocket 快照。
- [公开 API v2](./api-v2.md)：受限 API Key、公开服务器信息和自定义页面。
- [扩展插件](./extensions.md)：Lua 扩展包格式和示例。
- [面板更新器](./dashboard-updater.md)：校验、部署和失败回滚。
- [Docker 连接排查](./docker-troubleshooting.md)：浏览器到插件 API 的连接与容器日志。
- [隐私政策](./privacy-policy.md)：浏览器与服务器端的数据处理方式。
- [界面语言](./interface-localization.md)：面板语言设置与贡献翻译。
